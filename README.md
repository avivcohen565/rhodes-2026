# רודוס — מדריך לפי שעות היום

מדריך אישי לטיול ברודוס, **31.8–4.9**, מבסיס ב־Cook's Club Kolymbia עם רכב שכור.

כל התוכן נאסף מקישורי הטיקטוק שנשלחו בקבוצת הוואטסאפ "רודוס 26" — 11 סרטונים,
האתר של Tambakio והאינסטגרם של Kounna. כל מקום זוהה מהסרטון עצמו.

## מה יש בפנים

- **מפה** של החוף המזרחי עם כל המקומות, המלון באמצע. לחיצה על שם פותחת אותו ב־Google Maps.
- **חלוקה לבוקר / צהריים / ערב** — מה יש בכל מקום, טווח מחירים, ומרחק נסיעה מהמלון.
- **תוכנית ל־5 הימים** מקובצת לפי אזור, כדי למנוע נסיעות כפולות.
- **אינדקס מלא** של 25 המקומות, ממוין מהקרוב למלון ועד הרחוק.

## קבצים

| קובץ | מה זה |
|---|---|
| `index.html` | הדף עצמו. קובץ אחד, בלי תלויות. |
| `manifest.webmanifest` | מאפשר "הוסף למסך הבית" בנייד. |
| `icon.svg` | אייקון לאפליקציה. |

## שימוש בנייד

פותחים את הדף בדפדפן ואז **שתף → הוסף למסך הבית**. הוא ייפתח כמו אפליקציה, במסך מלא.
הדף עובד גם בלי אינטרנט אחרי טעינה ראשונה; רק הפונטים ייפלו לברירת מחדל.

## הערות על הנתונים

- **המחירים הם הערכות** לפי תפריטים וביקורות מקוונות, לא ציטוט מהסרטונים.
  היחיד שנאמר במפורש בסרטון הוא ש־Meltemi הכי זול למיטת שיזוף.
- **המרחקים** הם נסיעה ברכב מקולימביה, מעוגלים. תנועה בפליראקי ובכניסה לרודוס טאון
  יכולה להוסיף 10–15 דקות בערב.
- **המפה סכמטית** — קו החוף מקורב, המיקומים והמרחקים היחסיים נכונים.
- הזיהוי של סרטון Megan Grant כ־Tambakio הוא הסקה ולא אישור; השם לא מופיע בסרטון.
